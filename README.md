## 📌 Descrição do Projeto – Landing Page (Portfólio)


A aplicação foi pensada como um projeto de portfólio para demonstrar domínio em front-end moderno, componentização em React e uso avançado de estilização com Tailwind CSS, incluindo efeitos visuais, gradientes e integração com elementos 3D.

O layout prioriza identidade visual forte, responsividade e estrutura escalável para futuras integrações.

---

## ⚙️ Descrição Técnica

**Nome do projeto:**

`eavox-lp-react`

**Stack:**

* ⚡ **Vite** — ambiente de desenvolvimento rápido e otimizado
* ⚛️ **React** — arquitetura baseada em componentes
* 🎨 **Tailwind CSS** — estilização utilitária e design system customizado
* 🧱 **HTML5 / CSS3**
* 📱 **Responsividade (mobile-first)**

---

## 🧩 Funcionalidades e Recursos

* Estrutura de componentes reutilizáveis
* Layout futurista com efeitos de  **glow** , **blur** e gradientes
* Paleta de cores customizada via Tailwind
* Preparado para uso de **elementos 3D** (ex: Three.js / React Three Fiber)
* Organização de código voltada à escalabilidade
* Alta performance e build otimizado com Vite
* Pronto para integração com APIs, formulários e animações avançadas

---

## 🎯 Objetivo do Projeto

Demonstrar habilidades técnicas em:

* Desenvolvimento front-end moderno com React
* Criação de interfaces visuais avançadas
* Uso de Tailwind CSS para design consistente
* Preparação de projetos para integração com gráficos e experiências 3D
